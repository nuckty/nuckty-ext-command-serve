# nuckty-ext-command-serve

Локальная раздача собранного таргета nuckty через nginx. Расширение регистрирует `serve` и `stop` через `env.commands`.

## Использование

Установите как devDependency и добавьте `'nuckty-ext-command-serve'` в `ext` файла `config-nuckty.ts`. Требуются собранный таргет и `nginx` в `PATH`.

```bash
npx nuckty build
npx nuckty serve            # http://127.0.0.1:8080
# Или: npx nuckty serve --port 8081
# Во втором терминале из того же каталога:
npx nuckty stop
```

`nuckty serve [target] [--port N]` выбирает таргет, проверяет его каталог HTML, записывает `.build/nginx-serve.conf` для этого артефакта и запускает nginx на переднем плане. Сервер слушает loopback; порт по умолчанию — 8080. Для маршрутизации, сжатия и согласования изображений используется генератор конфигурации хостинга из ядра.

Без имени таргета выбирается первый объявленный. Порт должен быть целым числом от 1 до 65535. Конфигурация просмотра создаётся заново и не включает автоматически хуки, изменившие `nginx.conf` при сборке, или настройки Apache.

`nuckty stop` читает `.build/nginx.pid`, дважды проверяет команду и время запуска процесса и отправляет `QUIT` только распознанному экземпляру. Некорректный, чужой или повторно использованный PID вызывает отказ без сигнала. Очистка сборки сохраняет этот PID, конфигурацию запущенного сервера и журналы предпросмотра, позволяя остановить экземпляр после пересборки. Файлы предпросмотра принадлежат проекту; не запускайте несколько экземпляров в одном каталоге сборки.

Демоны валидации принадлежат расширению validate и завершаются самой командой `nuckty validate`. Реестра `env.daemons` нет.

## Спецификация

См. спецификацию ядра `ext-command-serve` в `openspec/specs/ext-command-serve/spec.md`. Модульные тесты проверяют жизненный цикл и идентификацию процесса; наличие nginx — отдельное условие нативной интеграции.

## Лицензия

MIT.

Управление процессом использует инструменты POSIX (`which`, `ps`, сигналы). Работа в Windows без окружения POSIX не проверена.

Интеграционные проверки команд с настоящим рантаймом в PATH запускаются через `NUCKTY_SERVE_NATIVE=1 npm test`. В CI этот режим обязателен; иначе сценарий с настоящим процессом явно пропускается.
